# open-rewindpix

給 Rewindpix PS135 底片風格數位相機用的非官方 App。它是一個網頁，放在相機的記憶卡上，手機連上相機的 Wi-Fi 就能打開，不用從 App Store 安裝。

> 這是個人研究專案，與 Rewindpix 無關，也沒有得到官方授權或支援。App 會改寫相機的設定，請自行承擔風險。目前只在韌體 V1.2.1D 上測試過。

## 可以做什麼

- **換底片**：把相機 C1～C3 三格換成內建的 16 款經典底片風格，或自己調的底片。
- **在手機上沖洗**：照片依拍攝時用的底片沖洗；每張都可以改選底片、調強度、曝光、色彩、顆粒等。
- **存到「照片」**：單張或整卷一次存進 iPhone 的「照片」App。
- **全部拿出**：整卷沖洗、存到手機，再從相機清除，這卷重新計算張數。
- **設定**：自動關機、每卷張數（1～99）、外觀。

自訂底片和每張照片的調整都存在記憶卡上，換一支手機打開也看得到。

## 需要準備

- PS135 相機（建議韌體 V1.2.1D）
- iPhone（Safari 或 Brave）
- 一台電腦，用來把檔案複製到記憶卡（只有安裝和更新時需要）

## 安裝

1. **下載**：在這個 GitHub 頁面按 **Code → Download ZIP**，解壓縮。
2. **複製到記憶卡**：把記憶卡接到電腦，將 `app` 資料夾**裡面**的 `app.html` 和 `APP` 資料夾，複製到記憶卡的最上層。完成後記憶卡應該長這樣：

   ```
   記憶卡/
   ├── app.html        ← 新增
   ├── APP/            ← 新增（圖示、樣本照片）
   └── DCIM/           ← 相機原本的資料夾，不要動
   ```

3. **第一次使用「存到照片」前**：手機在**有網路**的時候，用 Safari 打開一次
   https://loldotenv.github.io/open-rewindpix/saver/
   手機會存下這一頁，之後連著相機、沒有網路時也打得開。

## 連線與開啟

1. 記憶卡裝回相機，開機，按相機的 **WIFI** 鍵。
2. iPhone 到「設定 → Wi-Fi」連上相機的 Wi-Fi，預設密碼是 `12345678`。手機會顯示「沒有網際網路連線」，這是正常的，保持連線即可。
3. 用 Safari 打開 **http://192.168.1.254/app.html**。
4. 建議加到主畫面：Safari 下方的「分享 → 加入主畫面」。之後點主畫面的 PS135 圖示就能打開，全螢幕、沒有網址列。

每一頁右上角的標籤會顯示**這卷還剩幾張**。連不到相機時，它會變成紅色的「未連線 · 重試」，點一下可以重新連線。

## 使用方式

### 底片

- **換底片**：點上方 C1、C2 或 C3 其中一格，選一款底片就會寫進相機。
- **自己調底片**：點底片庫裡的「＋」，或點一款自訂底片來修改。
  - 上方的拉桿是**手機沖洗**的效果，存檔時才套用，之後還能改。
  - 「相機內調色」是**拍照當下**就做進照片的效果，事後無法更改。
  - 內建底片不能修改，可以在編輯畫面按「複製」，另存一份再改。
- 連著 Wi-Fi 時，在相機上切換 C1～C3 不會生效。要換格子拍照，先關掉相機的 Wi-Fi 再切換。

### 相簿與單張照片

點一張照片打開：

- **底片**：換一款底片套在這張照片上，下方可以調強度。
- **調整**：從這卷底片原本的設定開始，微調曝光、對比、色彩、顆粒等。
  - 調好後可以按「存成新底片」，或「更新」覆蓋這卷底片，以後拍的照片也會套用。
- **對照原圖**：按住照片右下角的對比圖示。
- **還原**：照片改過才會出現在右上角，按兩次確認，回到拍攝時的樣子。
- **刪除**：垃圾桶圖示，按兩次確認。
- **存到「照片」**：按右上角的分享圖示，選「儲存沖洗照片」或「儲存原始照片」。
  1. 會打開一個新分頁「存到照片」。
  2. 在新分頁按「**存到照片**」，再選「**儲存影像**」。
  3. 完成後分頁會自己關掉，回到 App。

所有調整都會自動儲存，關掉再打開也還在。

### 全部拿出（整卷存到手機並清空相機）

1. 在相簿按「**全部拿出**」，App 會一張張沖洗。沖洗時請停在這個畫面，不要切走。
2. 沖洗完按「**存到照片（N 張）**」，會打開新分頁。
3. 在新分頁按「**存到照片**」，再選「**儲存影像**」。完成後會回到 App。
4. 到「照片」App 確認照片都在了，回來按「**從相機清除**」，按兩次確認。相機裡的照片和隱藏備份會一起刪除，這卷底片重新開始計算張數。

### 設定

相機資訊、自動關機、每卷張數、外觀，以及恢復相機原廠設定。最下面顯示 App 的版本。

## 更新 App

1. 下載新版，把 `app/app.html`（和有變動的 `app/APP/` 檔案）複製到記憶卡，覆蓋舊檔。
2. 手機打開 App 時會自動發現新版並重新載入。可以到「設定」最下面確認版本號。

如果改了圖示，需要刪掉主畫面上的圖示，再重新「加入主畫面」。

## 常見問題

- **右上角一直是「未連線」**：
  - 確認手機連的是相機的 Wi-Fi；
  - 相機可能已經待機，按一下相機的按鍵喚醒，再點右上角的標籤重試。
- **按「存到照片」沒有跳出新分頁**：瀏覽器擋掉了彈出視窗，請允許這個網站開新視窗。用 Brave 的話，先把背景裡舊的「存到照片」分頁關掉。
- **「存到照片」頁面打不開**：要先在有網路的時候打開過一次，見「安裝」第 3 步。
- **格子顯示「相機設定不同」**：相機上的設定和這卷底片的不一樣。點那一格，再按「更新相機」。
- **格子顯示「不在底片庫」**：這是用其他 App 寫進相機的底片。點那一格，再按「加入底片庫」。
