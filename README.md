# open-rewindpix

給 Rewindpix PS135 底片風格數位相機用的非官方 App。它是一個網頁，放在相機的記憶卡上，手機連上相機的 Wi-Fi 就能打開，不用另外安裝。

> 這是個人研究專案，與 Rewindpix 無關，也沒有得到官方授權或支援。App 會改寫相機的設定，請自行承擔風險。目前只在韌體 V1.2.1D 上測試過。

## 功能

- **底片**：查看相機 C1～C3 三格裝的底片，換成內建或自訂的底片。自訂底片同時包含相機內調色（拍照時直接套用）和手機沖洗的設定。
- **相簿**：瀏覽相機裡的照片，依拍攝時用的底片在手機上沖洗。每張可以改選底片、調整強度、曝光、色彩、顆粒等。
- **全部拿出**：把照片沖洗後存到手機，再從相機清除，連同隱藏的 `._FILM` 備份一起清掉。
- **設定**：自動關機、每卷張數（1～99）、外觀。
- 自訂底片和每張照片的設定存在記憶卡的 `/APP/`，換一支手機也看得到。

## 安裝

1. 把記憶卡接到電腦，將 `app/app.html` 和 `app/APP/` 資料夾複製到記憶卡的**根目錄**。
2. 記憶卡裝回相機，打開相機的 Wi-Fi，手機連上（預設密碼 `12345678`）。
3. 用 Safari 打開 `http://192.168.1.254/app.html`。
4. 想要像 App 一樣使用：Safari 的「分享 → 加入主畫面」。

## 存到「照片」

相機只有 http，而 iOS 只讓 https 頁面用分享選單一次存多張照片。所以 App 會把沖好的照片交給 `saver/` 這個放在 GitHub Pages 上的小頁面（https://loldotenv.github.io/open-rewindpix/saver/），由它叫出分享選單。照片只在手機內傳遞，不會上傳。

第一次使用前，請在手機**有網路**時打開一次上面的網址，讓手機存下這一頁；之後連著相機的 Wi-Fi、沒有網路時也打得開。

這個流程還在測試中。

## 目錄

```
app/       放到記憶卡根目錄的 App（app.html、APP/ 裡的圖示與樣本照片）
saver/     「存到照片」的 https 小頁面，由 GitHub Pages 提供
scripts/   產生 App 圖示的腳本（make-icon.py，需要 Pillow）
```
